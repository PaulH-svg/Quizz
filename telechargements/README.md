# Télécharger Minuit

[**Minuit-portable.zip**](Minuit-portable.zip)

Sur GitHub, ouvrir le fichier ZIP puis cliquer sur **Download raw file** (icône de téléchargement). Extraire entièrement le dossier, installer [Node.js LTS](https://nodejs.org), puis double-cliquer sur `Lancer Minuit.bat` sous Windows. Le ZIP contient aussi les instructions Mac et Linux.

Le lanceur et les 30 questions sont inclus. Aucun `npm install` n’est nécessaire pour utiliser le dossier portable.
